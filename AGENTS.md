# Правила разработки

- Общайся с владельцем на русском языке.
- Выполняй только явно запрошенные изменения. Не придумывай игровые механики, контент, интерфейсы или дополнительные функции без разрешения.
- Не меняй существующий дизайн, расположение элементов и функциональность вне поставленной задачи. Не удаляй существующие функции без согласования.
- Если существенная деталь не определена, задай вопрос до реализации.
- Перед изменениями прочитай PROJECT.md и актуальный код. Код является источником истины о реализации.
- Сохраняй поддержку мобильных браузеров и GitHub Pages. Пока проект статический, без сервера и зависимостей.
- Не сбрасывай сохранения пользователя без разрешения.
- Проверяй изменённый функционал и отсутствие регрессий доступными средствами; сообщай, что реально проверено, и какие ограничения остались.
- После задачи кратко перечисли изменения. Не начинай следующий этап самостоятельно.
- Обновляй описание состояния в PROJECT.md при изменении реализованных функций.
